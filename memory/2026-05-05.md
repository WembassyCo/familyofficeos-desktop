## KidneyX Export Plugin — Bug Root Cause Found & Fixed (May 5, 2026, 7:55 AM)

**Issue:** v3.3.0 through v3.6.0 XLSX files reported as "corrupted"

**Root Cause Identified:**
- XML contained Unicode escape sequences: `\u003e` instead of `>`, `\u003c` instead of `<`
- JSON encoding was contaminating XML output
- Also literal `\n` instead of actual newlines

**Files Analyzed:**
- File size: 8KB (valid structure, just encoding issue)
- All 9 Open XML parts present and valid
- Shared strings: 220 items, properly counted
- 3 worksheets with correct data
- Only XML escaping was wrong

**Manual Fix Applied:**
- Downloaded corrupted XLSX from Mitzi
- Extracted worksheet XML files
- Replaced `\u003e` → `>`, `\u003c` → `<`, `\n` → newline
- Rebuilt XLSX archive
- Uploaded to Google Drive for Mitzi

**Plugin Fix:**
- v3.7.0 released by Spock with proper XML generation
- No JSON encoding in pipeline
- Uses `htmlspecialchars()` for proper escaping
- Raw string concatenation for XML tags

**Status:**
- Manual workaround file delivered to Mitzi
- v3.7.0 awaiting test confirmation
- Issue should be fully resolved
